UT4 Community Launcher

A small, source-available launcher for Unreal Tournament 4 community play — sign in, find a game and launch in one click, keep NetcodePlus up to date, and check your stats. The update path is cryptographically verified end to end (a signed manifest plus a key baked into the app), so getting set up never means trusting a random download.

Built by phantaci for the UTPugs / UT4 community. Open source under Apache 2.0. Not affiliated with Epic Games or the Unreal Tournament brand.

What NetcodePlus adds

NetcodePlus is the community gameplay plugin this launcher keeps updated — it brings extra modes and features to UT4:

  • Improved netcode & hit registration — tighter, more accurate online play.
  • Wipeout — UT's version of the mode from Diabotical.
  • Improved CTF — a refined Capture the Flag.
  • ElimPlus — an enhanced Elimination mode.
  • ncHUD — a customizable NetcodePlus HUD.
  • Higher FPS — supports frame rates up to 720 fps.
  • …and more.
